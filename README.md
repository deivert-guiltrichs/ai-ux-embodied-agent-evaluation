# Evaluación UX aumentada con IA para agentes virtuales corporizados

Este repositorio contiene la propuesta, documentación y estructura inicial del proyecto individual del curso PF-3311 Agentes Virtuales Inteligentes.

## Descripción

El proyecto propone construir y evaluar un agente virtual corporizado orientado a explicar conceptos básicos de bases de datos a estudiantes universitarios. La investigación compara la evaluación de experiencia de usuario realizada por usuarios humanos con una evaluación generada por un modelo de lenguaje a partir del mismo escenario de interacción.

## Objetivo general

Explorar la utilidad de un modelo de lenguaje como evaluador complementario de experiencia de usuario en un agente virtual corporizado académico.

## Estructura del repositorio

- `/docs`: documentos formales de entrega.
- `/prototype`: estructura inicial del prototipo del agente.
- `/evaluation`: instrumentos y protocolo de evaluación.
- `/prompts`: prompts preliminares para el agente y para la evaluación con IA.

## Advertencia de seguridad

No se incluyen API keys, credenciales ni datos personales en el repositorio.
